# SkyRadar – live flight radar for Android
1. Create a new GitHub repo; upload everything in this folder (on phone: Add file → Upload files; for `.github/workflows/build-apk.yml` use "Create new file", type that path, paste the contents of `build-apk.yml.copy`).
2. Actions tab → "Build APK" runs automatically (~5 min).
3. Open the Releases page of your repo on your phone, download `app-debug.apk`, install it (allow "install unknown apps").
Data: adsb.lol / airplanes.live (zoomed-in live detail), OpenSky (world view; anonymous rate limit applies).
